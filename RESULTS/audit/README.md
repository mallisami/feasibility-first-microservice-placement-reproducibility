# Audit evidence

This folder contains only audit records retained for the journal reproducibility package: environment/cluster qualification, ns-3 build qualification, the v0.3 scientific correctness gate, the experiment freeze/inventory, resource/replicate justification, and the reproducible randomized exact-vs-exhaustive audit.

Some frozen audit narratives contain historical absolute paths from the machine on which the original experiment was executed. Those strings are preserved as provenance; they are not current repository paths. Use the repository README/runbooks for current paths.
