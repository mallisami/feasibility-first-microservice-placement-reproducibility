# Supporting evidence

This directory contains supporting (non-primary) experiments used by the paper.

- `raw/` — source datasets from the controlled supporting campaigns.
- `canonical/` — validated frozen publication inputs used to generate the supporting paper tables.

Some canonical files are byte-identical to their raw source because the publication step is a validation-and-freeze operation rather than a numerical transformation. The duplicate is intentional and documented by `canonical/publication-source-manifest.*`.

These studies are not pooled with the primary v0.3 R1--R8 campaign.
